## About

This repository is no longer being actively maintained (and it is from a very very long time ago).


This repository contains the source code and assets for **Paint App v5.9**, a simple yet powerful (not really powerful, more goofy) painting application designed for creative projects and personal use. Built with Python, this app aims to provide a not smooth and interesting painting experience.

---

## Building on Windows

This project is packaged with PyInstaller.

### Requirements

- Python 3
- PyInstaller

Install PyInstaller with:

```bat
py -m pip install pyinstaller
```

### Build

Open Command Prompt or PowerShell in the project folder and run:

```bat
py -m PyInstaller --clean paint.spec
```

The finished application will be placed in:

```text
dist\
```


The `paint.spec` file contains the PyInstaller build configuration, including bundled files and application settings.
